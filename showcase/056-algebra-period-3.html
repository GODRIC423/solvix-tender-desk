Completing the Square

Objective: by the bell you can rewrite any quadratic y = ax² + bx + c in vertex form y = a(x − h)² + k and read the vertex straight off it — no calculator, no guessing.

Take half of b. Square it. Add it to both sides.

Example 1 solve for x

x² + 6x − 7 = 0
x² + 6x = 7move the 7 across first
x² + 6x + 9 = 7 + 9(6 ÷ 2)² = 3² = 9 ← both sides!
(x + 3)² = 16perfect square trinomial
x + 3 = ±4don't drop the ±
x = 1  or  x = −7
check: 1 + 6 − 7 = 0 ✓49 − 42 − 7 = 0 ✓

Example 2 vertex form when a ≠ 1

y = 2x² − 8x + 3
y = 2(x² − 4x) + 3factor the 2 out of the x-terms only
y = 2(x² − 4x + 4) + 3 − 8we really added 2 · 4 = 8, so take 8 back
y = 2(x − 2)² − 5
vertex (2, −5), opens up, minimum value −5

Watch out: the #1 lost point on last year's quiz was subtracting 4 instead of 8 here. Whatever you add inside the parentheses gets multiplied by the number out front.
